# CEUB-Projects

Organização dedicada aos projetos, atividades acadêmicas e estudos desenvolvidos durante minha segunda graduação em **Engenharia de Software** no CEUB.

O foco está no desenvolvimento de software com boas práticas de engenharia, arquitetura bem estruturada e código de qualidade.

## Áreas de atuação

- Desenvolvimento back-end
- APIs REST
- Java
- Banco de dados
- Arquitetura de software
- Desenvolvimento web
- Testes de software
- Atividades e projetos das disciplinas
